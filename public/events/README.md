Drop event photos here (e.g. `hackathon-2026.jpg`), then reference them
in `lib/events.ts` as `/events/hackathon-2026.jpg`.

Past-event gallery photos go in `gallery/` and are referenced as
`/events/gallery/photo-name.jpg`.

Keep images under ~500KB each — resize/compress phone photos before
adding them, so the site stays fast to load.
